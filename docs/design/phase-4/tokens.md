# Phase 4 foundation tokens

The foundation uses one warm, photographic neutral scale and one amber accent. Archivo carries controls and data; Newsreader gives headings an editorial voice. Numeric controls opt into tabular lining figures.

## Colors

| Role | Light | Dark |
| --- | --- | --- |
| Canvas | `#f6f1e8` | `#171512` |
| Panel | `#fffaf2` | `#211e1a` |
| Raised panel | `#fffdf8` | `#29251f` |
| Ink | `#29241e` | `#f4ecdf` |

| Border | `#d9cec0` | `#494139` |

## Type and shape

| Role | Token |
| --- | --- |
| Interface and data | Archivo Variable |
| Display | Newsreader Variable |
| Caption | `0.6875rem`, semibold, tracked uppercase |
| Region title | `2.25rem`, medium |
| Field gap | `0.75rem` |
| Control radius | `0.75rem` |
| Panel radius | `1rem` |
| Numeric figures | Tabular, lining |
